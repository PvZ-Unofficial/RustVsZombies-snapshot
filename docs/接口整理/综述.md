目前接口可以一下划分

low dsl接口：方便用户简写的接口，用于注册到时间轴，并在规定的时间调用，典型用法：
``` rust
(1, 225) << p(2, 9);                     // 225时机生效一个炸(2, 9)的炮
wave(1);
225 << p(2, 9);                         // 沿用当前波次
at(1, 225 - 373, || fire(2, 9));         // 普通函数注册，fire 从 rsvz::cob 或 prelude 导入
try_at(1, 225 - 373, || try_fire(2, 9))?; // 传播绑定错误；回调错误由执行通路处理
```

`at` 与 `try_at` 只接受三个参数，不提供 `at(时间)` 或 `at(波次, 时间)` 构造器。
需要将闭包组合进 DSL 表达式时使用 `(1, 时间) << act(|| { /* 操作 */ });`。
